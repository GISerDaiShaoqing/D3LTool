## 一、软件概述

D3L Tool of NASA Satellite（简称 D3LTool）是一款用于检索与下载美国 NASA
对地观测卫星数据的桌面应用软件，支持 MODIS、VIIRS（LAADS DAAC）与
MERRA-2（GES DISC）产品。软件以 NASA 官方 earthaccess 库与 CMR 检索服务
为基础，将登录、检索、下载全流程集成于同一图形界面内，提供中文/English
双语切换、可点击的正弦瓦片地图、多线程断点续传下载队列以及命令行接口。
v2.3 起还内置单像元时间序列采样与绘图：经 NASA OPeNDAP 直采数据
（MODIS/VIIRS 走 LAADS DAAC，MERRA-2 走 GES DISC），可在软件内直接查看
任一点位随时间变化的折线并导出 CSV，无需任何第三方子集服务。
v2.4 起提供浏览器辅助下载：勾选的检索结果可导出为 URL 清单（`.txt` 可直接
喂给 wget/aria2/下载管理器）与 HTML 索引页，直连受阻时改由已登录的浏览器
会话代为下载。v2.5 起进一步覆盖 GLASS 产品体系：公开的 glass.hku.hk 档案
（130+ 个产品变体）纳入同一检索-下载流程，全程无需任何登录。

本软件由戴劭勍开发。2018 年发布的 v1.0 采用浏览器模拟方式批量下载订单数据；
2026 年发布的 v2.0 在现代技术栈上整体重构，不再依赖浏览器，也不再需要去
NASA 网站人工创建订单。

## 二、运行环境

- 操作系统：Windows 10/11（64 位），或 macOS 12+，或主流 Linux 发行版
- 运行方式：双击独立安装包 `D3LToolNASA.exe`（Windows，无需安装 Python），
  或安装 Python 3.10+ 后执行 `python -m pip install -e .` 并运行 `d3ltool-gui`
- 网络：需访问 ladsweb.modaps.eosdis.nasa.gov、urs.earthdata.nasa.gov、
  disc.gsfc.nasa.gov、glass.hku.hk 等站点；支持在"设置"中配置 HTTP/SOCKS 代理

## 三、安装与启动

1. 从 GitHub Releases 或官网下载对应平台的安装包；
2. Windows 用户双击 `D3LToolNASA.exe` 直接启动（首次启动解压约 2-3 秒）；
3. macOS 首次打开如被 Gatekeeper 拦截，右键选择"打开"或执行
   `xattr -cr D3LToolNASA.app`；
4. 亦可 `pip install d3ltool` 后运行 `d3ltool-gui`（图形界面）或 `d3ltool`（命令行）。

## 四、主要功能与操作步骤

### 4.1 登录 NASA Earthdata 账号

1. 菜单"设置 → 登录 Earthdata"，输入在 https://urs.earthdata.nasa.gov 注册的
   用户名与密码（免费注册；用户名不是邮箱）；
2. 检索不需要登录；下载需要登录；
3. 登录成功后凭据持久化保存在本机用户目录的 `_netrc` 文件中（仅本机保存，
   不上传），下次启动软件自动恢复登录状态。

### 4.2 检索数据

1. 在左侧"产品"卡片选择产品组（MODIS Terra / Aqua / Combined、VIIRS、
   MERRA-2、GLASS），点击"产品目录"按钮可打开产品目录窗口浏览各卫星的全部产品、
   版本与中文说明，双击即可填入产品与版本；也可在"自定义产品 / Custom"分组
   直接输入任意 CMR short_name；
2. 选择开始/结束日期；
3. 选择区域（三种方式任选）：
   - 在正弦瓦片地图上直接点击选择 MODIS/VIIRS 瓦片（可多选，再点一次已选
     瓦片即取消，「清除瓦片」按钮一键全清），
     或在输入框中填写 `h04v03` 等瓦片号（多个用逗号分隔），
     或输入经纬度后点击"定位到瓦片"；
   - 在"经纬度范围 bbox"中填写左下/右上经纬度（适用于 MERRA-2 等数据）；
4. 点击红色"检索"按钮，检索结果显示在右上表格中（文件名/日期/瓦片/大小）；
   右上「清除结果」可一键清空该表。

### 4.3 下载数据

1. 在结果表中勾选需要的文件，点击"加入下载队列"；
2. 右下任务表实时显示每个文件的进度、速度与状态，支持暂停/继续/重试；
3. 已完成的文件再次下载会自动跳过，中断的文件自动断点续传；
4. 下载目录、并发数与代理在"设置"对话框中配置，设置保存在
   `~/.d3ltool/config.json`。

### 4.4 命令行接口

```
d3ltool login                                  # 登录并持久化凭据
d3ltool search VNP46A1 --start 2020-03-01 --end 2020-03-31 --tile h04v03
d3ltool download VNP46A1 --start 2020-03-01 --end 2020-03-31 --tile h04v03 --dest D:/data
d3ltool search M2T1NXSLV --start 2019-08-01 --end 2019-08-31 --bbox 100 20 120 40
```

### 4.5 AI 助手（v2.1 新增，v2.2 起为右缘悬浮抽屉）

1. 点击主窗口右缘的「AI 助手」按钮，聊天抽屉从右侧滑出（悬浮显示，
   不遮挡数据界面）；抽屉头部的「⚙ 设置」打开弹出式设置对话框；
2. 在设置对话框选择服务商（预置 DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI /
   SiliconFlow / Ollama 本地等 OpenAI 兼容接口），填写模型名与 API Key，
   点击"测试连接"验证，凭据只保存在本机 `~/.d3ltool/config.json`；
3. 在聊天框用自然语言提出需求，例如"2020 年 1 月北京的夜光数据帮我下载"，
   助手会调用检索、瓦片换算、下载排队等工具完成任务；
4. 也可让助手画点位折线图，例如"帮我画禹城 2010 年的 NDVI 序列"，助手
   取到序列后会直接把折线图画进时间序列抽屉（v2.3）；
5. AI 请求下载时会先弹出确认框；AI 发起的下载与手动下载共用同一个任务表；
6. Earthdata 用户名密码永远不会经过对话；对话记录只在当前会话内存中，
   关闭软件即清空。

### 4.6 MCP 服务器（v2.1 新增）

软件附带 `d3ltool-mcp` 命令（或安装包中的 `D3LToolMCP` 程序），通过
MCP（Model Context Protocol）把检索、瓦片换算、点位时间序列采样、绘图、
下载排队、清单导出等 13 个工具暴露给
Claude Desktop、Cursor、ZCode 等 AI 客户端，使外部 AI 助手可以直接下达
数据检索与下载指令；密码同样不作为工具参数，下载复用本机已登录凭据。
客户端配置示例见仓库 `docs/mcp.md`。

### 4.7 时间序列采样与绘图（v2.3 新增）

1. 点击主窗口右缘的「时间序列」按钮打开抽屉；
2. 选择产品（MODIS/VIIRS 的 LAADS short_name，或 MERRA-2 变量如
   M2T1NXSLV / M2TMNXSLV，及其图层）、输入纬度经度与起止日期，
   点击"绘制折线图"；
3. 软件经 NASA OPeNDAP 直采该像元的序列：MODIS/VIIRS 走 LAADS DAAC，
   MERRA-2 走 GES DISC 云网关，复用本机登录凭据，不经任何第三方子集服务；
4. 折线图直接显示在软件内，可一键导出 CSV（文件头注明图层与原生单位，
   如 T2M 的开尔文）；"清空"按钮将图表复位（表单保留，便于修改参数后
   重画）；
5. 采样期间显示实时进度（直采进度按 granule 逐条刷新），"停止"按钮可在
   两次取数之间中断；图层参数支持简称（≥3 个字符，忽略大小写/下划线/
   空格），提示无法解析时报错并附可用图层名，供修正后重试；
6. 该功能用于快速查看点位变化趋势等轻量场景；大范围、长序列的正式
   分析仍建议检索并下载原始数据后离线处理。

### 4.8 浏览器辅助下载（v2.4 新增）

1. 在检索结果表勾选需要的文件（或多选），点「在浏览器打开」：软件生成一张
   自包含的 HTML 索引页（文件名/日期/大小/链接）并弹进默认浏览器，可逐个
   点击下载，或用 Download It All / DownThemAll 类浏览器扩展在本页全选
   批量下载；
2. 点「导出下载清单」（结果表按钮）或「导出失败清单」（任务表按钮，仅失败
   任务）：生成 `.txt`（一行一个 URL，可直接作为 `wget -i` / `aria2c -i`
   或下载管理器的输入）与同名 `.html` 索引页，默认存于下载目录；
3. 任务表的失败清单是跨检索生存的救援线——下一次检索会覆盖结果表，而失败
   URL 在任务表里一直活着：某个下载反复收到 401/403（网络受限或访问协议
   未确认）时，点「导出失败清单」，完全跳过程序内的下载会话，由浏览器中
   已登录的 Earthdata 会话直接取文件；
4. 凭据安全：上述流程只动浏览器，软件不经手任何密码，对话/MCP 消息中
   亦无凭据。

### 4.9 GLASS 数据检索与下载（v2.5 新增）

1. 产品组选择"GLASS"，下拉列出公开 GLASS 档案（glass.hku.hk）的全部
   130+ 个变体（产品×来源×分辨率，如 `LAI_MODIS_250M`）；LAI/NDVI/EVI
   （MODIS 250m）、FVC（500m）与 Ta（逐日）五个变体经过实测核验，排在
   最前并在说明中标注"已核验"；
2. GLASS 检索不需要登录 Earthdata：档案是公开的 HTML 目录，软件按日期
   范围自动展开合成 DOY 文件夹并列出文件；区域选择与 NASA 数据完全一致
   （瓦片地图点选、`h04v03` 输入或经纬度范围框均可，范围框与正弦瓦片网格
   精确求交）。注意档案普遍滞后更新：首次使用请选档案已覆盖的年份
   （如 2000~2025），超出覆盖的日期段会得到明确提示；
3. 下载复用同一任务队列（断点续传、重试），全 GLASS 批次不要求登录；
   v2.4 的「导出下载清单」「在浏览器打开」对 GLASS 结果同样可用；
4. 未核验合成周期的变体，软件直接从档案目录推导年份/DOY 文件夹；个别目录
   布局特殊（气候态产品等）的变体会给出明确提示，建议改用 GLASS 官网或
   配合作者的 R 包 glass.sqdaitools（检索下载在本软件，terra 拼接/裁剪/
   缩放等后处理在 R 包完成）。

### 4.10 其他功能

- "网站"菜单：程序官网、作者博客与 NASA 官方入口；
- "遥感资源"菜单：整理的常用遥感资源清单；
- "帮助"菜单：打赏（支付宝收款码）与关于信息；
- "语言"菜单：中文 / English 一键切换（重启后生效）。

## 五、常见问题

1. **下载 401/403**：请确认 Earthdata 账号有效，并到 LAADS/GES DISC 网站登录
   并同意相应数据使用协议（EULA）；确认后若仍受限，可用 §4.8「导出下载清单」
   让已登录浏览器代为下载；
2. **下载速度慢**：请检查代理设置；LAADS/GES DISC 国内直连速度不稳定属正常
   现象，工具支持断点续传，中断后重试即可；
3. **登录提示 401**：用户名或密码不正确，请先在浏览器验证账号；
4. **文件未下载完整**：任务表显示"失败"时可右键重试，已下载部分自动续传。
