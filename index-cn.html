D3LTool

NASA 卫星的 D3L 工具

一款免费的桌面软件，一站式检索与下载 NASA MODIS / VIIRS / MERRA-2 数据——选产品、选时间、点瓦片、排队下载，全流程不出一个窗口。

内置检索

使用指南

三步开始

1

拿到软件

Windows 双击 D3LToolNASA.exe 即可（单文件，无需安装 Python）；在“设置”里用免费的 NASA Earthdata 账号登录 （检索无需登录，下载需要）。

2

检索

选产品、选时间，在地图上点出需要的瓦片，点 Search。

3

下载

勾选需要的文件加入队列，断点续传下载器会自动完成，失败还会重试。

安装与登录

Windows 双击 D3LToolNASA.exe 即可（单文件，无需安装 Python）；macOS .app 与 Linux 二进制在 GitHub Releases，命令行用户直接 pip install d3ltool。在 “设置 → 登录 Earthdata”里用免费的 NASA Earthdata 账号登录—— 检索无需登录，下载需要；凭据只保存在本机（~/.netrc）。

检索

左侧选产品组与产品（或“custom”输入任意 CMR short_name）， 可选版本（留空取最新）与起止日期；区域可以直接在正弦瓦片地图上点选（可多选， 或输入 h04v03，或用经纬度定位），MERRA-2 这类数据也可输入范围框。 点红色 Search 按钮，结果出现在右上表格。

下载

在结果表勾选文件，点“加入下载队列”。任务表实时显示每个文件的进度 与速度，可暂停/续传/重试；已完成文件重新下载时自动跳过，中断的自动续传。 下载目录、并发数与代理都在“设置”里。

# 命令行
pip install d3ltool
d3ltool search VNP46A1 --start 2020-03-01 --end 2020-03-31 --tile h04v03
d3ltool download VNP46A1 --start 2020-03-01 --end 2020-03-31 --tile h04v03 --dest D:/data
d3ltool search M2T1NXSLV --start 2019-08-01 --end 2019-08-31 --bbox 100 20 120 40

MCP 服务器与 AI 助手

d3ltool-mcp 通过 stdio 暴露 9 个工具（检索、瓦片换算、下载 控制），接入 Claude Desktop、Cursor、ZCode 等 MCP 客户端；软件内右缘滑出的 AI 助手抽屉用自然语言驱动同一套工具。配置示例见 接入指南。

菜单

“网站”菜单收录项目官网、作者博客与 NASA 门户；“遥感资源”是精选的遥感 资源列表；“帮助”含打赏与关于；界面语言在“语言”菜单一键切换。

历史

从 2018 到今天

D3L Tool 由戴博士创建于 2018 年（v1.0）——当时 LAADS FTP 服务器关停、官方 Python 脚本对非程序员 太不友好，v1 用浏览器模拟替用户自动下单。八年后技术栈全面更新，v2 基于 NASA 官方 earthaccess 库与 CMR 检索服务彻底重写。
