D3L Tool of NASA Satellite 2.0 介绍

NASA卫星的D3L工具是一款免费的软件工具，在软件内即可完成 NASA 卫星数据的检索与下载全流程。

v2.0 基于 NASA 官方 earthaccess 与 CMR 检索服务全面重构： 不再需要去 NASA 网站创建订单，也彻底告别浏览器模拟登录。左侧选择产品（MODIS / VIIRS / MERRA-2）、 时间范围，直接点击正弦瓦片地图选择区域（或输入经纬度），即可检索并勾选下载——内置断点续传、 多线程并发、失败自动重试与文件校验，中英双语界面，支持 Windows / macOS / Linux。

项目历史：NASA卫星的D3L工具由戴先生开发。2018 年 v1.0 因 LAADS FTP 服务器关闭、官方脚本对非程序员不友好而生，通过浏览器模拟批量下载订单数据。 八年后技术栈全面更新，v2.0 让它重新成为最好用的 NASA 数据下载工具之一。


v2.0 主界面

左侧检索（产品 / 时间 / 可点击的 36×18 瓦片地图），右侧检索结果与下载队列实时进度。


v2.0 新特性

  • 内置检索：按产品、时间、瓦片（h##v##）或经纬度范围检索，无需去 NASA 网站下单
  • 产品覆盖：MODIS、VIIRS（LAADS DAAC）与 MERRA-2（GES DISC），也可输入任意 CMR short_name
  • 健壮下载：多线程队列、分块进度、HTTP 断点续传、失败自动重试、文件大小校验
  • 中英双语：菜单一键切换中文 / English
  • 跨平台：Windows exe、macOS .app、Linux 二进制（CI 自动构建），也支持 pip install d3ltool
  • 代理支持：适应复杂网络环境


开始使用

Windows 用户直接双击 D3LToolNASA.exe（单文件，无需安装 Python）： 在"设置"中登录 NASA Earthdata 账号（免费注册，检索不需要登录、下载需要）， 选择产品与区域后点"检索"，勾选文件加入下载队列即可。

命令行用户：pip install d3ltool 后即可 d3ltool search VNP46A1 --start 2020-03-01 --end 2020-03-31 --tile h04v03。 详见文档。
